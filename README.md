# cet6-xiexiu · 六级逆向分析项目

以正确答案为锚点，逆向分析六级真题的命题规律，产出可执行的复习方法。目标：425 及格。

## 从哪开始（学习文档）

按"先背 → 再系统学 → 深挖细节"三层用：

| 文档 | 用途 |
|------|------|
| **一页速记卡.md** | 打印揣兜里，考前最后一眼扫全部要点 |
| **六级保命手册.md** | 主文档，六步学习路径 + 可直接背默写的成品模板 |
| 调研_仔细阅读.md | 阅读 C：做题判断树 + 四类干扰项 + 替换词表 |
| 调研_段落匹配.md | 阅读 B：七步流程 + 要背的词族表 |
| 调研_选词填空.md | 阅读 A：11 类"结构→词性"对照 + 逐题表 |
| 调研_翻译.md | 翻译：成品骨架 + 6 段真题套用 + 填空素材包 |

四份 `调研_*` 由子代理回原始数据逐题倒推，是深度素材库；手册和速记卡是它们的精简执行版。

## 核心结论速览（已按逐题复核修正）

- **Section C**：正确答案 62% 实词是改写、53% 连全文都找不到原词——"找原词"是错的；干扰项词面重合比正确项还高，越眼熟越危险。⚠️ "第 n 题去 n/5 区段"经复核只有 53/120 题成立（44%），**已降级为警报器，不是定位公式**。
- **Section B**：10 题对应 10 个不同段落、相邻不撞段（120/120 零例外）——排除法王牌；题目顺序≠段落顺序，跳段是常态；字母 D/H/J 最热，P/Q/R 各仅 1 次。
- **Section A**：词性只排除不锁定——纯词性 0 题能剩到唯一答案，过滤后平均仍剩 7.6 个候选。性价比最低，5 分钟到就蒙。
- **写作**：第 1 句原样抄题目句是真题铁律（10/10）；正文用通用套话模板，只换"题目关键词"。
- **翻译**：12 段中 9 段考"中国发展成就"、3 段考传统美德；先拆中文再套成品骨架，成就类 making 收尾、美德类 helping/inspiring 收尾。
- **听力**：项目内无听力原文/音频，无法倒推规律；只做两件事——背职场+校园场景词、蒙题别押单一字母。
- ⚠️ 机构答案键不可盲信：本项目修正了 xdf 聚合页 12 处 + NJU 解析 5 处答案错误（均经原文复核）。

## 目录结构

```
cet6-xiexiu/
├── 01-papers/       # 真题与解析 PDF（21 份；2025.06 三套为扫描件，靠 OCR 提取）
├── 02-parsed/       # PDF 导出文本 (*_raw.txt) + 结构化 JSON (parsed/)
├── 03-analysis/     # 学习文档 + 分析报告 + 逐题明细（见上表）
├── scripts/         # 全部管线脚本（可重跑）
│   ├── parse_cet6.py        # PDF→JSON（答案键/词库/题目选项）
│   ├── analyze.py           # 分模块统计
│   ├── ocr_pdfs.py          # 扫描件 OCR（rapidocr）
│   ├── normalize_ocr.py     # OCR 文本归一化
│   ├── reverse_secC.py      # 逆向：来源句定位/同序/替换对
│   ├── reverse_secAB.py     # 逆向：词性/段落匹配
│   └── reverse_writing.py   # 逆向：写作/翻译模板
└── README.md
```

## 环境

- Python 3.13 + `.venv`（pymupdf、rapidocr-onnxruntime，不进 git）
- Windows / Git Bash

## 更新方式

1. 新考次 PDF 放入 `01-papers/`；扫描件跑 `scripts/ocr_pdfs.py`
2. 导出文本后，在 `scripts/parse_cet6.py` 的 `SETS` 注册并运行
3. `scripts/analyze.py` + `scripts/reverse_*.py` 重新生成统计报告
4. 学习文档需人工按新数据修订（子代理可重新逐题倒推生成 `调研_*`）
5. 答案键务必双源一致或原文复核后再入库
